匯入支出與借款（進階）

把你的資產負債表 Excel 轉成 JSON 後匯入，首頁的「累積收入曲線」會多一條線：從今天起每月扣掉生活支出的 12 個月平均（往後一直推算），再扣掉每月還款：銀行信用貸款、循環額度、保單借款的本金＋利息，以及股票質押的利息（質押本金不還）。

怎麼轉出 JSON
  1. 在你的電腦安裝 Python 與 openpyxl（pip install openpyxl）。
  2. 執行：python tools/xlsx_to_json.py 資產負債表.xlsx，會產生 private/ltl-advanced.json（此資料夾已被 git 忽略）。
  3. 在下方選擇這個檔案。轉出的檔案只有「生活支出月平均」、各貸款的類型／餘額／利率、「每月借款利息與本金」、股票質押的已借金額與利息，以及持股現值；不含銀行名稱、股票代號、信用卡明細與家人戶頭。

轉換只支援原表的版面（需要「每月支出」「月度彙總」「借款總表」「股票質押」工作表）。生活支出月平均是 Excel 12 個月資料的平均；若有月份的信用卡還沒輸入，平均會偏低。

JSON 格式範例（不用 Excel，自己填寫也可以）

下面是一份虛構的範例，月份從下個月起排 36 個月。你可以複製或下載後改成自己的數字，再用下方「匯入」選擇檔案。也可以把目前匯入的資料匯出，備份或換瀏覽器時再匯入。

欄位說明（金額一律是新台幣整數；利率用小數）
欄位型別必填說明
version數字必填格式版本，填 2（1 也能匯入，會當作沒有借款餘額、股票等欄位）。
exportedAt文字選填資料日期，例如 2026-11-06，只用來顯示。
livingMonthlyAvg數字必填生活支出的「12 個月月平均」（NT$）。曲線與餘裕會從今天起每月扣這筆。
months陣列必填每個月的借款還款，最多 600 筆，月份不可重複。沒列到的月份視為 0。
months[].ym文字必填月份，格式 YYYY-MM，例如 2026-12。
months[].interest數字必填當月各貸款利息合計（NT$，不含股票質押利息）。
months[].principal數字必填當月各貸款本金合計（NT$）。每月還款＝利息＋本金。
months[].parts物件選填依類型拆開：credit（銀行信用貸款）、revolving（銀行循環額度）、policy（保單借款），各有 interest、principal。用於逐月明細。
loans陣列選填目前的各筆貸款：type（credit／revolving／policy）、balance（目前餘額 NT$）、rate（年利率，0.035 代表 3.5%）；美元保單借款可加 usd（美元本金）。不要放銀行名稱。
pledge物件選填股票質押：borrowed（已借金額）、rate（年利率）、monthlyInterest（每月利息）、stockValue（質押標的現值），金額單位 NT$。假設本金不還、持續展延。
holdings陣列選填持股：code（股票代號）、market（TWSE 上市或 TPEX 上櫃）、shares（股數）、price（股價）、pledged（是否質押，true／false）。用於「線上更新股價」。
fx數字選填USD/TWD 匯率，用於美元借款換算。
stockValueFree數字選填未質押持股現值（NT$），算進資產的投資。

匯入時會檢查格式，錯誤會說明哪裡不對；檔案超過 500 KB 會被拒絕。匯出的檔案含你的財務數字，請自行保管，不要上傳到公開的地方。

線上更新股價與匯率（選用）

只有你按下按鈕時才會連線，不會自動更新。會連到兩個地方：臺灣證券交易所（上市股票收盤價，只送出你持股的股票代號，不送股數與其他資料）與 ExchangeRate-API（USD/TWD 匯率，非官方牌價，不送出任何資料）。上櫃股票沒有可從網頁直接讀取的官方來源，會沿用匯入的價格。更新後的股價與匯率只存在這個瀏覽器，並用來重算持股現值與美元保單借款。
