匯入支出與借款（進階）

把你的資產負債表 Excel 轉成 JSON 後匯入，首頁的「累積收入曲線」會多一條線：從今天起每月扣掉生活支出的 12 個月平均（往後一直推算），再加上 Excel 算出的每月借款利息。

怎麼轉出 JSON
  1. 在你的電腦安裝 Python 與 openpyxl（pip install openpyxl）。
  2. 執行：python tools/xlsx_to_json.py 資產負債表.xlsx，會產生 ltl-advanced.json。
  3. 在下方選擇這個檔案。轉出的檔案只有「生活支出月平均」與「每月借款利息、本金」，不含信用卡明細、家人戶頭與股票帳戶。

轉換只支援原表的版面（需要「每月支出」「月度彙總」工作表）。生活支出月平均是 Excel 12 個月資料的平均；若有月份的信用卡還沒輸入，平均會偏低。
